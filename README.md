# Mini E-Commerce

A responsive and interactive e-commerce web application built to provide a simple and intuitive online shopping experience.

## Live Demo

[View Live Demo](https://bright-piroshki-d096fc.netlify.app/)

## Overview

**Mini E-Commerce** is a frontend web application that demonstrates the core functionality of an online shopping platform.

The application focuses on creating a clean shopping experience where users can browse products, explore product details, and interact with products through a responsive and user-friendly interface.

This project was developed to strengthen practical skills in **React.js, component-based architecture, state management, and responsive frontend development**.

## Features

* Browse available products
* View product information
* Interactive product interface
* Add products to the shopping experience
* Responsive design
* Reusable React components
* Dynamic UI updates
* Clean and intuitive user interface

## Technologies Used

* **React.js** – Component-based frontend development
* **JavaScript** – Application logic and interactions
* **HTML5** – Application structure
* **CSS3** – Styling and responsive design
* **Netlify** – Deployment

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd mini-ecommerce
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL displayed in your terminal.
